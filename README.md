# Polaris Pay Documentation

Official technical documentation for the Polaris Pay ecosystem.

- **Status:** Active
- **Framework:** Next.js + MDX
- **Website:** [docs.polarispay.app](https://docs.polarispay.app)

## 🚀 Overview

Polaris Pay is an institutional-grade fintech layer built on the Ethereum blockchain, providing yield optimization and decentralized credit infrastructure.

### Key Sections:
- **Protocol Architecture:** In-depth explanation of our three-layer system.
- **Getting Started:** Guides for users to begin depositing and borrowing.
- **Developer Guide:** Integration details for the Polaris SDK.

## 🛠️ Development

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Local Setup
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
